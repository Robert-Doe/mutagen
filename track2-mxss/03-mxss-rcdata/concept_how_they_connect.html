Mutation XSS is one leaf on a family tree. Knowing where it sits keeps you from applying the wrong defence.

03

Commonly confused pairs

The wrong statementThe correction
"We sanitise with DOMPurify, so we can't have mXSS."mXSS is the failure mode of a sanitiser. It is specifically what a sanitiser misses. Historic DOMPurify bypasses are mXSS.
"mXSS and DOM XSS are different problems."mXSS is DOM XSS — the subclass where a sanitiser was in the path and got out-manoeuvred by serialise+reparse.
"A strict CSP stops mXSS."It stops the payload executing (no inline handlers, no eval), which is real defence-in-depth — Module 11. It does not stop the mutation; the dangerous node is still built.
"DOM clobbering is a kind of XSS."No script is injected. It corrupts a variable a script later trusts. Different mechanism, different fix. Named here only to keep it separate.
"Output encoding fixes mXSS."Output encoding fixes reflected/stored XSS. mXSS happens after the value is already a trusted string in the browser; there is nothing left to encode.
04

Scenario-matching quiz

A search page reflects ?q= into <h1>Results for X</h1> server-side, unencoded. Which kind?

Reflected XSS. Fix: encode on the server. No sanitiser, no browser re-parse involved.

A rich-text comment is run through a client-side allow-list sanitiser, and the sanitised HTML is assigned to commentEl.innerHTML. An attacker finds an input the sanitiser passes but the browser parses into a live handler. Which kind?

Mutation XSS. The sanitiser is in the path and its output re-parsed differently. Fix: loop-to-fixed-point sanitising, namespace enforcement, or the native Sanitizer API (Module 11).

An attacker submits <a id=defaultView><a id=defaultView name=x>; later the page's own script does window.defaultView.x. Which kind?

DOM clobbering. Not XSS — no attacker script runs. The page's own script reads an attacker-controlled node.

A user pastes fetch('/api/keys').then(...) into their browser console because a "tutorial" told them to. Which kind?

Self-XSS. Defence is a console warning banner and user education, not code.
