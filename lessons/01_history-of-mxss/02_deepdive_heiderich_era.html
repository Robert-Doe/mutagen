The Heiderich Eraand why regex sanitizers lost

The 2013 CCS paper didn't find a bug. It found that the whole category of "clean the HTML string" was unsound — and it did so by attacking the one operation everyone trusted: reading .innerHTML back out.

01

What the paper actually claimed

"mXSS Attacks: Attacking well-secured Web-Applications by using innerHTML Mutations", Heiderich / Schwenk / Frosch / Magazinius / Yang, ACM CCS 2013. The core claims:

  • When you set el.innerHTML = s and then read el.innerHTML back, the browser does not return s. It returns serialize(parse(s)) — and that is a different string.
  • The difference is not random. It follows the serializer's rules, and an attacker can steer it: choose an s that is inert, but whose serialization — or whose serialization re-parsed — is not.
  • Therefore any sanitizer that inspects a string and emits a string, without accounting for what the browser will do on the next parse, is bypassable by construction. Not "has a bug". Is unsound.

This is exactly the result Modules 2 and 9 reproduce with our engine, thirteen years later, against Chrome 148: serialize(parse("a<b>c")) is "a<b>c</b>". The identity fails even for trivial input.

Four of five families closed by serializer hardening. The fifth — namespace — needed sanitizers to change, and is the one Module 5 still demonstrates firing.

03

Why regex lost, precisely

A regex sees a ribbon of characters. The browser sees a tree, built by a state machine with 80 states and a stack. The regex asks "does this substring look like onerror=?". The browser asks "given everything above me on the stack and which tokenizer state I'm in, is this an attribute?". Those are not the same question, and no amount of regex cleverness closes the gap — because the gap is Turing-machine vs. finite automaton, formally.

Module 3 shows two decades-old regex bypasses still working against a realistic string filter: <img/onerror=alert(1)//src=x> (no whitespace before on) and <a href=&#106;avascript:…> (entity-encoded scheme). The same two payloads are stopped cold by the tree walk in the same module. That contrast is the Heiderich result, in miniature.
